Zevo flying insect trap

Zevo is a small plug-in with a blue light and a sticky card. It is for fruit flies and gnats, not for a wasp nest. Start with the base plus a refill.

Put it near the fruit bowl or the trash. Swap the card when it looks ugly. It will not fix a drain that is breeding gnats.

If the problem is ants, use bait. If the problem is wasps outside, this device is the wrong aisle.
